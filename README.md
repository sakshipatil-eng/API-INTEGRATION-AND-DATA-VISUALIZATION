# 🌦️ Weather Visualization App (Python)

This is a simple Python application that fetches **real-time weather data** for a given city using the **OpenWeatherMap API** and visualizes key weather parameters using **Matplotlib**.

The app displays:
* Weather description
* Current temperature
* Feels-like temperature
* Humidity
* A bar chart for visual comparison


## 📌 Features

* Fetches live weather data from OpenWeatherMap
* Displays weather details in the console
* Visualizes weather parameters using a bar chart
* Easy to customize for different cities


## 🛠️ Technologies Used

* Python
* Requests
* Matplotlib
* OpenWeatherMap API

## 📂 Project Structure

weather_data.py
README.md

## ⚙️ Requirements

Make sure you have Python installed (Python 3.x recommended).
Install required libraries using:
bash
pip install requests matplotlib


## 🔑 API Key Setup

1. Create an account at **OpenWeatherMap**
2. Generate your API key
3. Replace the API key in the code:
python
API_KEY = "your_api_key_here"

## ▶️ How to Run the Program

1. Open terminal / command prompt
2. Navigate to the project folder
3. Run the file:
bash
python weather_app.py

## 📊 Output

* Weather details printed in the console
* A bar chart showing:
  * Temperature (°C)
  * Feels Like (°C)
  * Humidity (%)

## 🏙️ City Customization

You can change the city name in the code:
python
city_nm = "Kolhapur"
